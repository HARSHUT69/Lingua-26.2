LINGUA - Minecraft 26.2 chat translator (Fabric)

JAR KAISE BANAYE (GitHub, PC pe kuch install nahi):
1. github.com pe new repository banao (Public ya Private).
2. Is zip ko extract karo, andar ke saare files/folders (src, .github, build.gradle, ...) repo me upload karo
   ("Add file" -> "Upload files").
3. Repo ke "Actions" tab me "build" run hoga (2-4 min).
4. Run complete hone par neeche "Artifacts" me lingua-jar download karo, zip me .jar milega.
5. Jar ko mods folder me daalo (Fabric Loader + Fabric API chahiye, Java 25).
